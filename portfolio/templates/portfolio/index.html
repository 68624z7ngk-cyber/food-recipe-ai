01 / ABOUT

About

Python / Djangoを使ったWebアプリケーションの 設計・開発・デプロイまでを一通り経験しています。

Djangoの URL routing / View / Template / Model / ORM を利用し、PostgreSQLとのデータ連携や 外部APIとの連携を実装しています。

また、画像を扱うアプリケーションでは Cloudflare R2をオブジェクトストレージとして利用し、 Gemini APIによる画像解析・文章生成など、 複数のサービスを組み合わせた構成にも取り組んでいます。

Environment Variables

APIキー、データベース接続情報、 R2の認証情報などの機密情報は ソースコードに直接記述せず、 環境変数から取得しています。

os.getenv("GEMINI_API_KEY")
os.getenv("DATABASE_URL")
os.getenv("R2_ACCESS_KEY_ID")
